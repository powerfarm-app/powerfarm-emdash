# Security

Powerfarm protects devices, identities and approvals for a small organisation
under active attack. Please report vulnerabilities privately.

- **Report:** use GitHub's *Report a vulnerability* button on this repository
  (Security → Advisories). Do not open a public issue, pull request or
  discussion about a vulnerability.
- **Never post** secrets, tokens, keys, certificates, device identifiers,
  hostnames of private systems or logs in issues or pull requests.
- **Scope:** `plugin/`, `site/`, `mac/`, `scripts/`, `upstream/patches/` and the
  workflows in `.github/`. Vulnerabilities in EmDash itself belong to
  [EmDash's security policy](https://github.com/emdash-cms/emdash/security).

What does not depend on secrecy: everything in this repository is public on
purpose. Protection rests on keys held by people and machines (never in this
repository) and on approvals recorded in Powerfarm.
